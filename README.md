# GeoKuk se přestěhoval

Vývoj GeoKuku pokračuje v komunitní verzi. Tento repozitář se dál nevyvíjí.

- **Web, stažení, novinky:** [geokuk.cz](https://geokuk.cz)
- **Zdrojový kód, hlášení chyb, nápady:** [github.com/geokuk-community/geokuk](https://github.com/geokuk-community/geokuk)
- **Nejnovější verze:** [vydání komunitní verze](https://github.com/geokuk-community/geokuk/releases/latest)
- **Návody a příručka:** [wiki komunitní verze](https://github.com/geokuk-community/geokuk/wiki)

## Co tu zůstává

- [Vydání 3.5.1 až 5.2.0](https://github.com/marvertin/geokuk/releases) ke stažení. Starší verze 5.x z nich kontrolují a stahují aktualizace.
- Uzavřené issues a pull requesty z let 2015 až 2026 jako archiv.
- Větev `master` s historií verze 5.x. Totéž je v komunitním repozitáři jako tag `archiv/master`, spolu se všemi tagy vydání.

Kód ve větvi `main` je kopie komunitní verze z 8. 11. 2026 a není aktuální.
